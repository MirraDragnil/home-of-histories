# Шаблон страницы рассказа

Это ручная HTML-заготовка для Home of Histories, а не генератор сайта. Заполнители вида `{{TITLE}}` сами по себе браузером не обрабатываются.

## Новый рассказ

1. Скопируйте `story-template.html` в `stories/ffxiv/<slug>.html` или соответствующий каталог другой вселенной.
2. Замените все заполнители `{{...}}`: название, мир, каталог изображений, обложку и её alt, дату первой публикации в ISO-формате (`YYYY-MM-DD`) и в читаемом виде, жанры/предупреждения, серию и текст.
3. Для обложки с центральной композицией добавьте класс `hero--center` к элементу `hero`.
4. Внутри `article.markdown` допустимы иллюстрации, заголовки и индивидуальная HTML-разметка, включая существующие классы `dream-section`, `reality-tear` и другие из `styles/story.css`.
5. Вручную добавьте карточку в `stories/<world>/index.html`; при необходимости обновите счётчик на главной. Для карточки указывайте ту же дату первой публикации в атрибуте `datetime`.
6. Проверьте новую страницу и каталог локально в браузере, затем сделайте merge обычным способом.

## Редакции и архив

Дата на карточке — дата **первой публикации**, даже если рассказ впоследствии переработан. Дату существенного обновления можно показывать отдельно. Архивную ссылку добавляем только тогда, когда архивная редакция действительно создана.

Не заменяйте опубликованные тексты, изображения и установленный литературный канон автоматически. Технический шаблон не определяет каноничность произведения.

## Пути

Шаблон рассчитан на глубину `stories/<world>/<slug>.html`: ссылки `../../styles/...` и `../../assets/...` корректны именно для неё. Файл в `templates/` — только исходная заготовка и не предназначен для просмотра как готовая страница.
